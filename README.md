## `> philosophy`

Uma coisa mudou bastante na forma como estou estudando programação.

Durante alguns projetos anteriores, acabei dependendo demais de código
gerado por IA.

O projeto funcionava.

Mas existia um problema:

```txt
código funcionando ≠ conhecimento
```

Por isso, atualmente tento seguir outro processo:

```txt
entender
   ↓
escrever
   ↓
executar
   ↓
errar
   ↓
ler o erro
   ↓
corrigir
   ↓
entender novamente
```

IA continua fazendo parte do meu aprendizado, mas como ferramenta para
explicar conceitos, revisar raciocínio e ajudar quando encontro problemas.

Não como substituta do processo de aprender.
