## `> projeto`

### PC Monitor

> Aplicação desktop para visualização e monitoramento de informações do computador.

O **PC Monitor** é um projeto planejado em Python com o objetivo de reunir informações do hardware e apresentá-las através de uma interface própria.

```text
PC Monitor
│
├── CPU
├── Memória RAM
├── GPU
├── Armazenamento
└── Informações do sistema
```

A proposta é manter o projeto simples inicialmente e evoluí-lo conforme o desenvolvimento das funcionalidades.

**Objetivos principais**

- detectar informações do computador;
- organizar dados de hardware;
- apresentar informações de forma clara;
- desenvolver uma interface desktop própria;
- aplicar Python em um projeto com finalidade real.

`Python` `Desktop` `Hardware` `Monitoring`
